# پورتفولیوی شخصی

سایت انگلیسی و چپ‌به‌راست با HTML و CSS خالص؛ بدون وابستگی، بیلد، دیتابیس یا سرویس خارجی. تصاویر نمایشی با CSS ساخته شده‌اند و فونت از سیستم بازدیدکننده استفاده می‌کند.

## شخصی‌سازی

در `index.html` نام، معرفی، مهارت‌ها، عنوان صفحه و توضیحات SEO را ویرایش کنید. کارت‌های پروژه نمونه هستند. برای نمایش کار واقعی، محتوا را عوض کنید و در صورت نیاز لینک پروژه را با عنصر `a` اضافه کنید. هر دو مورد `hello@example.com` (آدرس نمایشی و `mailto`) را با ایمیل خود جایگزین کنید. رنگ‌ها در ابتدای `assets/style.css` تعریف شده‌اند.

## اجرای محلی

از ریشه پروژه:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

این سرور فقط برای توسعه است؛ cPanel فایل‌های سایت را مستقیماً ارائه می‌کند.

## آپلود روی cPanel

1. در cPanel وارد Domains شوید و Document Root دامنه موردنظر را پیدا کنید. برای دامنه اصلی معمولاً `public_html` است؛ دامنه‌های دیگر ممکن است پوشه متفاوتی داشته باشند.
2. از فایل‌های قبلی هاست نسخه پشتیبان بگیرید. فایل `index.html` و پوشه `assets` را در Document Root قرار دهید؛ پوشه بیرونی پروژه را آپلود نکنید.
3. اگر از فایل ZIP آماده استفاده می‌کنید، آن را در Document Root آپلود و Extract کنید. پس از استخراج ZIP را از هاست حذف کنید.
4. ساختار نهایی باید `public_html/index.html` و `public_html/assets/style.css` باشد. پوشه `.git` و README را روی هاست آپلود نکنید.
5. اگر `index.php` یا صفحه پیش‌فرض دیگری وجود دارد، پس از پشتیبان‌گیری آن را حذف یا تغییر نام دهید تا صفحه جدید نمایش داده شود.
6. دامنه را باز کنید و منو، ظاهر موبایل و لینک ایمیل را بررسی کنید. HTTPS را از SSL/TLS Status یا AutoSSL هاست فعال کنید. اگر دامنه هنوز به هاست وصل نیست، DNS را مطابق راهنمای شرکت میزبان تنظیم کنید.

مسیر CSS نسبی است؛ سایت هم در ریشه دامنه و هم در یک زیرپوشه مانند `public_html/portfolio` کار می‌کند. فرم ارسال پیام وجود ندارد؛ دکمه ایمیل برنامه ایمیل بازدیدکننده را باز می‌کند.

## ساخت بسته آپلود

از ریشه پروژه، خروجی را خارج از checkout بسازید:

```sh
mkdir -p /workspace/artifacts
zip -r /workspace/artifacts/portfolio-cpanel.zip index.html assets
```
